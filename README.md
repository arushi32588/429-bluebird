# Git 2 - Branching, Rebasing, and Pull Requests
This activity is to help familiarize you with GitHub and it's controls which we will use throughout this semester.
We aim to practice and learn:
- Creating your own branches in the repository.
- Git rebasing
- Creating Pull Requests and approving them
- Dealing with merge conflicts and code reviews.
- Branch protection
- Tracking issues and continuous integration.
